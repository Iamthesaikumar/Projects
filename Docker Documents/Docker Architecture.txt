| If you see...                        | It means...     | Programming Language | Runtime to Install        |
| ------------------------------------ | --------------- | -------------------- | ------------------------- |
| `package.json`                       | Node.js project | JavaScript           | ✅ Node.js Runtime         |
| `.java`, `pom.xml`, `build.gradle`   | Java project    | Java                 | ✅ JDK / JRE               |
| `requirements.txt`, `pyproject.toml` | Python project  | Python               | ✅ Python Runtime          |
| `.csproj`, `.sln`                    | .NET project    | C#                   | ✅ .NET SDK / .NET Runtime |
